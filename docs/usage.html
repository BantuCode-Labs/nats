Panduan Penggunaan NATS

Selamat datang di dokumentasi resmi NATS ERP. Ikuti panduan ini untuk menginstal dan menjalankan sistem di lingkungan lokal atau produksi Anda.

Instalasi

NATS memerlukan Node.js versi 20.x atau lebih baru. Pastikan Anda sudah menginstal Git dan PostgreSQL sebelum memulai.

Langkah 1: Clone Repository

git clone https://github.com/maziyank/nats.git
cd nats

Langkah 2: Install Dependensi

npm install

Konfigurasi

Salin file .env.example menjadi .env dan sesuaikan nilai-nilainya.

cp .env.example .env

Pastikan variabel DATABASE_URL mengarah ke instance PostgreSQL Anda:

DATABASE_URL="postgresql://user:password@localhost:5432/nats"

Persiapan Database

1. Buat Database

psql -U postgres -c "CREATE DATABASE nats;"

2. Migrasi Schema

npx prisma generate
npx prisma migrate dev --name init

3. Seed Data Awal

Anda dapat memilih antara seeding lengkap untuk pengujian atau seeding minimal untuk mulai dari awal.

Opsi A: Lengkap (Disarankan untuk Demo)

npm run prisma db seed

Opsi B: Minimal (Clean Start)

npm run prisma:seed:minimal

Modul Accounting

Modul akuntansi di NATS memungkinkan Anda mengelola seluruh siklus keuangan perusahaan secara otomatis.

  • Chart of Accounts (COA): Atur struktur akun keuangan Anda.
  • Jurnal Umum: Catat transaksi manual dengan sistem double-entry.
  • Buku Besar: Lacak mutasi setiap akun secara detail.
  • Laporan Keuangan: Neraca, Laba Rugi, dan Arus Kas tersedia secara instan.

Modul Inventory

Kelola persediaan barang Anda dengan fitur manajemen gudang yang canggih.

  • Manajemen Produk: Tambahkan produk dengan varian dan kategori.
  • Multi-Warehouse: Lacak stok di berbagai lokasi gudang.
  • Mutasi Barang: Catat perpindahan stok antar gudang atau penyesuaian stok.

Point of Sale (POS)

Interface kasir yang cepat untuk transaksi retail harian.

Buka menu POS untuk mulai melakukan penjualan. Sistem mendukung shortcut keyboard, pencarian produk cepat, dan integrasi dengan printer thermal untuk cetak struk.
